AgentVerse ⚔️

Watch your AI agent fight.

AgentVerse turns an AI agent's real problem-solving workflow into a live, side-scrolling pixel-art JRPG battle — the agent is the hero, your task is the boss, and every tool call becomes a skill cast. A gamified observability + interaction layer for agents that still delivers the real, cited answer.

⚡ Powered by Grok + the X API
▶ View on GitHub Explore features

WHAT IT DOES

🧙 Side-scrolling JRPG battle

The hero journeys through a scrolling scene, fighting a foe at each workflow step, ending at a boss. Melee heroes dash & slash; mages cast bolts.

⚡ Tool calls = skills

Grok's native web search, X search, and code execution become the agent's signature moves — "Intel Summon", "Forge".

📜 The real answer, delivered

The agent's actual streamed answer + clickable sources appear in a persistent result panel and the victory card. The game is the wrapper; the answer is real.

🔀 Gamified ⇄ observability

Flip the battle log to a real Agent Flow trace, and the quest track to a Live chain of the actual steps — unknown length, growing from a "?".

🎨 Human-in-the-loop designer

Co-create your hero with parallel Grok "design agents": concept → candidate pixel sprites → refine → forge. Combat VFX matched to the character.

🧰 Gear, hexagon stats & leveling

Equip gear across six ability axes; equipped skills control the agent's real tools. Quests grant XP and grow what the agent actually practiced.

HOW IT WORKS — THE EVENT → BATTLE SPINE

User task → POST /api/run ── streamText(Grok, { web_search, x_search, code_execution }) → fullStream events re-emitted as SSE → runAgent reads the stream → eventMapper — the one place deciding what a step means in the fight → battle store (zustand) — HP · log · flow · the real answer → React components animate the JRPG battle
